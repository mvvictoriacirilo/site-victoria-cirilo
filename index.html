💗 Atualizar o site da Victória

Esta ferramenta funciona no seu computador, sem enviar seu site a nenhum servidor. Ela acrescenta a seção de consultas, vacinação e exames, preservando suas fotos e o restante do site.

1 Baixe o index.html atual do seu GitHub

No repositório site-victoria-cirilo, abra index.html e use o botão de baixar arquivo (Download raw file).

2 Selecione o arquivo que você baixou
3 Gere a versão atualizada
Selecione seu arquivo para começar.

Depois de baixar o novo index.html, substitua o antigo no GitHub. Guarde uma cópia do arquivo antigo antes de publicar. Este atualizador foi preparado para a versão do site identificada em 10/11/2026.
